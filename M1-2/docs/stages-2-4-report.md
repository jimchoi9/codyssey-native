## 구현 및 로컬 검증

- CSV 전체 검증 후 적재, BOM·중복·오류 행 처리, 기존 기록 보존, 중단 후 재실행.
- 대화 생성·목록·상세·삭제, UTC 시각, 트랜잭션으로 동시 메시지 보존 및 삭제된 대화 재생성 방지.
- 최신 공통 요약과 최근 20개 메시지를 사용하는 Chat Completions, 저장 성공 후 응답, 실패 시 안전한 오류.
- AI 클라이언트 지연 초기화: 빈 데이터에서는 키나 AI 연결 상태와 관계없이 안내 메시지 저장.
- 백엔드 113개, 프론트 단위 15개, 브라우저 HTTP 대체 12개, 실제 로컬 FastAPI+fake 브라우저 통합 2개 통과.
- Python 3.13에서 검증. 보너스 기능은 미구현·범위 제외.

## 실제 연결과 배포

- 사용자 준비: main push, Render/Vercel 연결·환경 변수·Secret File 등록 완료.
- 공개 API 주소와 Vercel 공개 config.js의 연결 일치 확인.
- SDK로 지정 프로젝트 story-analytics-assistant 접근 확인. CSV 적재 전 data 컬렉션 0개.
